# CSS JAVA

Готовый GitHub-ready каркас меню.

## Меню

- Home — Roblox avatar, username, User ID, session time, script status.
- Movement — только Speed Hack ON/OFF. Скорость фиксирована в коде: 30.
- ESP — заготовка.
- Aim — заготовка.
- Other — заготовка.
- Settings — заготовка.
- Config — заготовка.

## Assets

Положите реальные PNG-файлы в `assets/`. Файл `assets/asset_manifest.json` содержит пути к ним.

> Важно: GitHub сам по себе не превращает PNG в Roblox Image Asset. Способ отображения удалённых изображений зависит от среды запуска. Поэтому загрузчик вынесен в отдельный модуль.

## Запуск

`main.lua` — точка входа проекта. Конкретный способ загрузки модулей/ассетов должен соответствовать среде исполнения, которую вы используете.
